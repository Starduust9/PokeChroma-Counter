# Compteur Shiny

Logiciel Windows qui regarde ta carte d'acquisition (Elgato, caméra virtuelle OBS…) ou la
fenêtre de ton logiciel de capture, **compte chaque rencontre** et **t'alerte** (son, Discord,
capture d'écran) quand le Pokémon est shiny. Tu joues à la main, le logiciel ne fait que regarder.

## Télécharger

👉 **[Télécharger la dernière version](https://github.com/Starduust9/compteur-shiny/releases/latest/download/Compteur-Shiny.zip)**

Décompresse le zip, ouvre le dossier **Compteur Shiny** et lance **CompteurShiny.exe**
(rien à installer, Python inutile). Si Windows affiche « Windows a protégé votre ordinateur » :
**Informations complémentaires → Exécuter quand même**.

Le mode d'emploi complet est dans `LISEZ-MOI.md`, à l'intérieur du zip.

## Mises à jour

Le logiciel vérifie tout seul au lancement s'il existe une nouvelle version et propose de
l'installer. Tes chasses, sons et réglages sont conservés.
Tu as une version 1.4 ou plus ancienne ? Décompresse simplement le nouveau zip par-dessus ton
dossier actuel (une seule fois) : ensuite les mises à jour se feront automatiquement.

Toutes les versions : [Releases](https://github.com/Starduust9/compteur-shiny/releases)
